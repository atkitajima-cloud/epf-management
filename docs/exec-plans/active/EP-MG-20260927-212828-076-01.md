# Done Taskの完了日時表示と降順ソートを改善する

## 目的

Done列では完了日だけを比較しているため、同日に完了したTaskを実際の完了時刻順で確認できない。既に保存しているタイムゾーン付きの`actual_completed_at`を利用し、秒単位の表示と降順ソートを行う。

## 対象範囲

- `app/lib/markdown.js`の共通ボードソートを、`actual_completed_at`優先の降順へ変更する。
- `app/public/kanban-order.js`のDone列ソートを共通方針へ合わせる。
- `app/public/app.js`で完了日時を日本時間の秒単位で表示する。
- 同時刻、または実完了日時がない既存Taskについて、`completed_at`、Task IDの順で安定させる。
- 単体テストを追加・更新する。

## 対象外

- `completed_at`の形式変更および既存Taskのデータ移行。これは日本時間の完了日として互換性を維持する。
- WBSの表示・並び順変更。今回の対象はKanbanのDone列である。

## 実施手順

1. 完了日時の比較と表示に必要な小さな共通処理を定義し、`actual_completed_at`、`completed_at`、Task IDの優先順位をテストで固定する。
2. 共通ソートとブラウザ側のDone列ソートを同じ比較規則へ変更する。
3. Doneカードに日本時間の年月日・時分秒を表示する。
4. `npm test`、記録検査、差分レビューを実行する。
5. TaskとExecPlanに実施・検証結果を記録し、保存APIの証跡付きでTaskを`review`へ遷移する。

## 検証方法

- `actual_completed_at`が同日の異なる時刻であるDone Taskが、新しい順に並ぶことを単体テストで確認する。
- 完了日時が欠ける既存Taskが日付、Task IDの順に安定して並ぶことを確認する。
- 表示用日時が日本時間の秒単位になることを確認する。
- `npm test`と`node scripts/check-records.mjs`が成功することを確認する。

## 完了条件

- Done列で秒単位の完了日時を確認できる。
- Done Taskが完了日時の降順で並ぶ。
- 既存の`completed_at`形式と過去Taskの扱いを壊さない。
- 自動テストと記録検査が成功する。

## リスク・未確定事項

- 旧Taskには`actual_completed_at`がないものがあるため、値がない場合の比較規則を明示して回帰テストで守る。
