# 背景

EPF PoCでは、Task管理機能を作るだけでなく、`epf-management` を使ってPoC自体のTaskを運用し、Markdown / Gitを正本とする管理方法を実証する。

# 要求

PoCの目的、仕様、設計、実行計画は `epf-project` を正本とし、日々の実行Task、担当、状態、依存関係は `epf-management` で管理する。

# 受入条件

- EPF PoC用の実TaskをEPF Management上で追跡できる。
- Taskの変更履歴をGitで確認できる。
- PoC完了時に、結果を `epf-project` の実行計画へ反映できる。
