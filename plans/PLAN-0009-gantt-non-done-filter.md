# ガントの状態フィルタに完了以外を追加する

## 目的

ガント画面の状態フィルタで、完了済みTaskを除外して未完了Taskだけを確認できるようにする。

## 対象範囲

- `app/public/gantt.js` の状態フィルタに「完了以外」を追加する。
- 「完了以外」を選択したとき、`status: done` のTaskを除外する。
- 初回表示時の状態フィルタを「完了以外」にする。
- 既存の「すべて」「進行中（Doing / Review）」および個別状態のフィルタを維持する。

## 対象外

- Taskの状態値やTask Markdownの変更。
- API、server、ガントの集計カード、ほかのフィルタの変更。

## 設計判断

- フィルタは既存どおり、`/api/gantt` が返すTask一覧に対してブラウザ側で適用する。
- 新しいフィルタ値は既存の状態値と衝突しない `not_done` とする。
- 表示ラベルは「完了以外」とする。
- 条件は `task.status !== 'done'` とし、backlog、ready、doing、reviewを対象にする。将来状態値が追加されても、`done` 以外は表示対象となる。
- 初期状態の `state.filter.status` は `not_done` とする。利用者は「すべて」を選択して完了済みTaskを再表示できる。

## 実装ステップ

1. `fillSelect` の状態フィルタ用追加選択肢に「完了以外」を追加する。
2. `filteredTasks` の状態条件へ `not_done` の分岐を追加する。
3. 初回表示時の状態フィルタが「完了以外」であることを確認する。
4. `npm test` を実行する。
5. ブラウザでガント画面を開き、初回表示で完了済み13件が非表示、進行中・Readyの実PoC Taskが表示されることを確認する。

## 検証

- 「すべて」で全Taskが表示される。
- 初回表示で「完了以外」が選択され、`done` のTaskが表示されない。
- 「完了以外」で `done` のTaskが表示されず、`doing` と `ready` のTaskが表示される。
- 「進行中（Doing / Review）」と個別状態のフィルタが従来どおり動く。
- `npm test` が成功する。

## リスク

- `not_done` をTaskの実状態として扱うと、個別状態の選択肢と混同するおそれがある。フィルタ専用値として分岐で処理し、Task Markdownへ保存しない。
