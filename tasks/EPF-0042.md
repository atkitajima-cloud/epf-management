# 背景

OpenAPI定義を契約の正本としているが、testが正本を読んでおらず、frontendは型を手書きで保持している。契約と実装が乖離しても検出できない。

# 目的

契約の対応版を固定し、契約と実装の適合を自動で検証する。

# 完了条件

- [ ] ExecPlanを作成し、人間レビューで実装範囲と検証方法を確認できる状態にする。
- [ ] IMP-05の完了条件のうち、採用した範囲を満たす。
- [ ] 意図的に契約と実装を食い違わせると、自動検証が失敗する。
- [ ] frontendとbackendが参照する契約の版を特定できる。
