# 背景

EPF PoCでは `epf-project`、`epf-management`、`epf-backend`、`epf-frontend` が独立したGit repoとして存在する。現在のTaskはfrontendとbackendへの関連付けしか表せず、project・management・複数repoにまたがる共通作業を識別できない。

# 目的

各Taskについて、対象となるrepoまたは共通作業であることをEPF Management上で一貫して記録・表示・絞り込みできるようにする。

# 完了条件

- [ ] `epf-project`、`epf-management`、`epf-backend`、`epf-frontend`、共通を表現できる対象リポジトリのデータモデルを定義している。
- [ ] Taskの作成・編集・一覧・Kanban・ガントで対象リポジトリを一貫して扱える。
- [ ] 複数repoにまたがるTaskを共通として明示できる。
- [ ] 既存Taskの扱いと移行方針を記録し、自動テストで確認している。
