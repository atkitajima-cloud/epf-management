# 背景

ガントには先行Taskの情報があるが、どのTask同士が依存しているかを一覧で把握しにくい。

# 目的

ガント上でTaskの依存関係と依存方向を分かるようにする。

# 完了条件

- [ ] 依存元と依存先のTaskをガント上で対応付けて確認できる。
- [ ] 依存関係がないTaskと区別できる。
- [ ] 既存の依存関係・日程・進捗表示が壊れていないことを確認している。
- [ ] 自動テストとブラウザ確認の結果を記録している。
