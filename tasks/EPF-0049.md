# 背景

repo内Skillは`.agents/skills/`に置いており、Codexは自動検出するがClaude Codeは検出しない。各repoのAGENTS.mdは`review`／`done`への変更前にSKILL.mdを読むことを義務付けているため、検出されないツールでは規約を守れないか、黙って手順を飛ばすことになる。

利用者の開発環境ではCodexとClaude Codeを併用しており、Codexの利用制限が開発速度の制約になっている。ツールを切り替えられる状態にすることで制約を解消する。

# 目的

Skillの実体を`.agents/skills/`に一本化したまま、Claude Codeからも同じSkillを参照できるようにする。

- [x] `epf-task-execplan-sync`と`epf-code-review`の参照ファイルを配置する。
- [x] Claude Codeで両Skillが認識されることを人間が確認する。
- [x] 認識されない配置があれば、探索先を特定して修正する。
