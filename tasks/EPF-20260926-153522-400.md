# 背景

Taskを物理削除すると、過去のExecPlan・設計書からの参照が切れ、画面からも履歴が失われる。さらに削除直後のCommit & Pushでは削除済みのパスをstageしようとして失敗した。

# 目的

Task削除を論理削除へ変更し、削除済みTaskをdone列に「削除済み」として保持・表示する。

# 完了条件

- [x] ExecPlanを作成し、人間レビューで削除済みTaskの保存・表示方針を確認できる状態にする。
- [x] 削除操作がTask Markdownを残し、削除日時を記録してdone列へ移す。
- [x] 削除済みTaskが通常の完了Taskと区別して画面へ表示され、再編集・再削除できない。
- [x] Markdown検証、削除API、Git Commit & Pushの回帰テストが成功する。
