# 背景

EPF-0019でfeature branchからPull Request、review、main merge、Pipelineまでを一周するため、frontendとbackendにまたがる最小の実変更が必要である。現行のTask管理PoCは一覧・追加・編集・status更新までを実装済みであり、削除機能を追加すると最小CRUDが揃う。

# 目的

Taskを物理削除する最小機能をfrontendとbackendへ追加し、EPF-0019のPull Request検証に使用する。

# 完了条件

- [ ] ExecPlanを作成し、人間レビューで承認する。
- [ ] backendに`DELETE /v1/tasks/{taskId}`を実装し、削除成功と未存在Taskのテストを追加する。
- [ ] frontendに削除前の確認操作と、成功時に一覧からTaskを除去する表示を実装する。
- [ ] ローカルで削除機能を確認し、backendの自動testを実行する。
- [ ] 高リスク変更としてAIコードレビューを実施し、指摘・修正・検証結果を記録する。
- [ ] EPF-0019のfeature branch・Pull Request・review・main merge・Pipeline検証へ引き渡せる状態にする。
