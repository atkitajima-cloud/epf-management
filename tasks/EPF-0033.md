# 背景

EPF-0019でfeature branchからPull Request、review、main merge、Pipelineまでを一周するため、frontendとbackendにまたがる最小の実変更が必要である。現行のTask管理PoCは一覧・追加・編集・status更新までを実装済みであり、削除機能を追加すると最小CRUDが揃う。

# 目的

Taskを物理削除する最小機能をfrontendとbackendへ追加し、EPF-0019のPull Request検証に使用する。
