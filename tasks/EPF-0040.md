# 背景

frontendのPipelineはCIとdeployの双方にsource artifactを渡し、deploy段階で再buildする。CIの成功が、実際に配布したビルドの正しさを保証しない。

# 目的

検証した成果物と配布した成果物を一致させ、障害時に切り分けられるようにする。

# 完了条件

- [ ] ExecPlanを作成し、人間レビューで実装範囲と検証方法を確認できる状態にする。
- [ ] IMP-03の完了条件のうち、採用した範囲を満たす。
- [ ] 配布物と検証結果を対応付けて確認できる。
- [ ] 人間の受入確認中に次のdeployが始まる場合の扱いを定める。
