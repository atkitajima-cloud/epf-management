# 背景

AI-DEF-0011では、確認質問への回答を越えて台帳更新とTask作成を実行した。AI-DEF-0012では、対象repoと適用規則の照合なしにfeature branchを作成・pushした。いずれも品質ゲートの不足が根因である。

# 目的

書込み操作とGit操作の前に、利用者の明示指示、対象repo、適用規則を確認する品質ゲートを設計・実装する。

# 完了条件

- [ ] 確認質問だけでは台帳更新・Task作成・状態変更を行わない品質ゲートを定義する
- [ ] Git操作前に対象repo・利用者の明示指示・repo固有規則を照合する品質ゲートを定義する
- [ ] AI-DEF-0011とAI-DEF-0012の対策・検証結果を記録する
