# 背景

EPF-0035作成時に`target_repo: backend`を指定したが、EPF Managementが受け付ける保存値は`epf-backend`である。そのためTaskは無効扱いとなり、カンバン一覧から表示されなかった。

# 目的

対象リポジトリの不正値によるTask表示漏れを防ぎ、Task作成者が問題をその場で把握できるようにする。

# 完了条件

- [x] Planを作成し、人間レビューで入力検証・警告表示・自動testの範囲を確認できる状態にする。
- [x] Taskの対象リポジトリに許容する保存値と表示名の対応を一箇所で管理する。
- [x] 新規Task作成・更新で不正な対象リポジトリを保存できない、または正しい保存値へ正規化する。
- [x] Markdownを直接編集して不正値になったTaskも、カンバンまたは明確なエラー表示から確認でき、黙って見えなくならない。
- [x] 正常値・不正値・表示名の変換を自動testで確認する。
