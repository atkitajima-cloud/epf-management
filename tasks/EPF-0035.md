# 背景

EPF-0033のTask削除実装では、AIコードレビュー後に人間のローカル受入確認でDELETEのCORS preflight不備を検出した。初回レビューはCORSのOriginとAPI routeを個別に確認したが、追加HTTPメソッドがlocal serverとAPI Gatewayの許可メソッドへ含まれることを確認観点にしていなかった。

# 目的

HTTP APIのメソッド追加・変更時に、`epf-code-review`がroute、local CORS、API Gateway CORS、OPTIONS preflightの整合を確認できるようにする。人間のローカル受入確認・公開環境確認は維持する。

# 完了条件

- [ ] `epf-code-review`に、HTTPメソッド変更時だけ適用するCORS整合確認の観点を追加する。
- [ ] local serverとAPI Gatewayの許可メソッド、OPTIONS preflightの検証結果または未実施理由を報告できるようにする。
- [ ] Skillを構文検証し、EPF-0033の削除差分または同等のHTTP API変更で観点を試行する。
- [ ] 試行記録へ結果を追記し、人間のローカル受入確認・Amplify確認を置き換えないことを確認する。
