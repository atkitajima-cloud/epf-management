# 背景

計画の呼称をExecPlanへ統一するため、Task Front Matterの`plan`を`exec_plan`へ変更する。現在の`plan`は形式検証がなく、値が誤っていても検出できない。ExecPlanは4repoに分散するため、番号だけでは一意に識別できない。

# 目的

Front Matterの項目名を`exec_plan`へ統一し、repo名を含む値の形式を検証できるようにする。

# 完了条件

- [ ] ExecPlanを作成し、人間レビューで実装範囲と検証方法を確認できる状態にする。
- [ ] `plan`を`exec_plan`へ置き換え、テンプレート、serialize順、更新の許可項目、自動testを揃える。
- [ ] `exec_plan`の値をrepo名を含む形式で検証し、不正値を保存できないことを自動testで確認する。
- [ ] 既存の`plan`を持つTaskが、無効扱いにならず表示され続けることを確認する。
