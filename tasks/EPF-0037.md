# 背景

EPF-0020では、実施済みの完了条件にチェックが付いておらず、人間が不整合を発見して指摘する必要があった。EPF-0035では対象リポジトリの保存値が不正で、Taskがカンバンから表示されなかった。

AIが起こした不備を個別の会話やTask本文だけに残すと、同種の再発防止、Skill・AGENTS.md・テストへの還流状況を横断して追えない。

# 目的

AI作業中に起きた不備を、検出者、検出段階、影響、原因、即時対応、再発防止、後続Taskとともに記録し、必要な改善が完了するまで追跡できる最小の仕組みを設計・実装する。

# 完了条件

- [ ] 記録対象とするAI起因の不備、対象外とする単なる仕様変更・人間判断を区別する基準を定める。
- [ ] 不備記録の正本の配置、記録項目、関連Task・ExecPlan・commit・検証結果へのリンク方法を定める。
- [ ] 不備を検出した時の記録、原因分類、即時対応、再発防止の後続Task化、完了確認の流れを定める。
- [ ] Task完了条件の未チェック、front matter不正による表示漏れを最初の実例として記録する。
- [ ] Task／ExecPlan同期Skill、AIコードレビューSkill、AGENTS.mdのうち更新すべき入口を判断し、必要な実装を後続Taskへ引き渡す。
