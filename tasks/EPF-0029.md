# 背景

現在のガントはTaskの保存順で行を表示するため、先行Taskが後続Taskより下に表示される場合がある。その場合、依存関係の矢印が上向きになり、次に着手すべきTaskを判断しにくい。

# 目的

表示中のTaskを依存関係に従って並べ、先行Taskを後続Taskより上へ表示することで、矢印を原則として下向きにする。

# 完了条件

- [x] 表示中の先行Taskが後続Taskより上に並んでいる。
- [x] 循環依存を除き、依存矢印が下向きに表示される。
- [x] 独立Taskの並び順が安定している。
- [x] フィルタ、日・週切替、Taskクリック、既存のガント表示が壊れていないことを確認している。
- [x] 自動テストとブラウザ確認の結果を記録している。
