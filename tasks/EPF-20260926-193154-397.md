# 背景

現状はRequirement、Task、ExecPlanがリンクで辿れる一方、ExecPlanから実装commitへは一貫して辿れない。要求から実装までのトレーサビリティを、品質ゲートを増やさずに完成させる。

# 目的

実装を伴うTaskを`done`にする際、`epf-task-execplan-sync`がExecPlanへpush済みcommitのリモート履歴リンクを記録する運用を定義する。

# 完了条件

- [x] ExecPlanを作成し、リンク記録の対象・例外・更新タイミングを定義した。
- [ ] `epf-task-execplan-sync`の`done`手順に、実装commitリンクの記録確認を追加した。
- [ ] ExecPlanテンプレートへ実装記録の書式を追加した。
- [ ] AI Skill運用の設計書へ、push済みcommitリンクを記録する運用を追加した。
- [ ] 実装Taskと設計・調査Taskの扱いを明記し、既存のhook・API・品質ゲートを変更しないことを確認した。
- [ ] 関連ドキュメントのリンク検査と差分確認を成功させた。

# メモ

commitリンクはリモートGitサービス上の不変なcommit URLを用いる。実装不要のTaskは、ExecPlanの実装記録に理由を記載する。
