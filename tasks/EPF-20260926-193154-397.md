# 背景

現状はRequirement、Task、ExecPlanがリンクで辿れる一方、ExecPlanから実装commitへは一貫して辿れない。要求から実装までのトレーサビリティを、品質ゲートを増やさずに完成させる。

# 目的

実装を伴うTaskを`review`へ進める際、`epf-task-execplan-sync`がExecPlanへpush済みcommitのリモート履歴リンクを記録・確認する運用を定義する。`done`では同じ記録が残っていることを再確認する。

# 完了条件

- [x] ExecPlanを作成・承認し、リンク記録の対象・例外・更新タイミングを定義した。
- [x] `epf-task-execplan-sync`の`review`手順に実装commitリンクの記録確認を、`done`手順に最終状態の再確認を追加した。
- [x] ExecPlanテンプレートへ実装記録の書式を追加した。
- [x] AI Skill運用の設計書へ、push済みcommitリンクを記録する運用を追加した。
- [x] 実装Taskと設計・調査Taskの扱いを明記し、既存のhook・API・品質ゲートを変更しないことを確認した。
- [x] 関連ドキュメントのリンク検査と差分確認を成功させた。

# メモ

commitリンクはリモートGitサービス上の不変なcommit URLを用いる。実装不要のTaskは、ExecPlanの実装記録に理由を記載する。
