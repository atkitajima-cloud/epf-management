# 背景

AGENTS.mdの規約はほぼ文章であり、機械が止めない。リンク切れ、Front Matterの不正値、完了条件の未達は、これまで人間の目視で検出してきた。AI駆動開発の初心者が5人になると、規律の遵守を人の注意力に頼れない。

# 目的

規約違反を機械で検出し、人間のレビューへ届く前に落とす。検査は読み取り専用で再現可能とする。

# 完了条件

- [x] ExecPlanを作成し、人間レビューで実装範囲と検証方法を確認できる状態にする。
- [ ] IMP-01の6種類（相対リンク、Task Front Matter、statusと完了日、未チェック条件、TaskとExecPlanの状態、実装記録）を検査する。
- [ ] 既知の不整合（現在の切れリンク、不正な`target_repo`、`done`かつ未チェックの完了条件）を再現入力で検出できる。
- [ ] 導入後の実Taskは受入証跡なしでアプリ経由の`done`へ保存できず、直接編集した場合も無効Taskとして検出される。導入前の完了Taskは記録した経過措置で区別する。
- [ ] 未承認ExecPlanに紐づく実装差分は、commit前検査で止まる。
- [ ] 迂回可能な経路（`--no-verify`、直接のGit操作など）を列挙し、サーバー側で塞ぐ分をEPF-0039へ引き渡す。
- [ ] 検査失敗時に非ゼロの終了コードを返し、各repoの作業手順から実行できる。
