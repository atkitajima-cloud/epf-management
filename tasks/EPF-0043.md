# 背景

全37Taskが`done`だが13件に未チェックの完了条件が残り、`progressForTask`は`done`を無条件に100%として扱う。旧ダミーTaskと実Taskが同じ状態に集約され、完了の意味が一意でない。

# 目的

完了の定義を確定し、未達のまま完了扱いになっているTaskを是正する。指標の前提となる日付・状態の意味も定める。

# 完了条件

- [x] ExecPlanを作成し、人間レビューで実装範囲と検証方法を確認できる状態にする。
- [ ] IMP-06の完了条件のうち、採用した範囲を満たす。
- [ ] 実Taskの完了条件の未達がゼロになる、または例外理由が記録されている。
- [ ] リードタイムの起点（起票、着手のいずれか）を定義し、`start`が予定日であることと区別する。
